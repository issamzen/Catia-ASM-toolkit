## 📌 Overview

**Engineering Surface – CATIA V5 ASM Automation Toolkit** connects directly to an active CATIA V5 session and provides a complete environment for inspecting assemblies, managing metadata, generating bills of materials, and automatically creating structured drawings.

The toolkit helps engineers:

- Browse and inspect complete CATIA product structures
- Edit component properties and metadata
- Control component visibility
- Duplicate assembly components
- Generate professional Excel BOM reports
- Export CSV reports
- Create CATDrawing sheets with title blocks and parts lists
- Improve assembly documentation workflows
