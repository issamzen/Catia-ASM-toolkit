# Changelog

All notable changes to this project are documented here.

## [3.1.0] - 2026-08-10

### Added

- Professional Microsoft Excel BOM export
- Optional CATIA component thumbnails in Excel
- BOM summary worksheet with assembly statistics
- Material quantity summary
- Missing-property data-quality indicators
- CATPart and CATProduct color coding
- Excel totals, filters, frozen headers, and print-friendly formatting
- Support and Contact toolbar window
- Clickable support email and Engineering Surface YouTube link

### Changed

- Added a dedicated spreadsheet icon matching the existing toolbar design
- Improved toolbar spacing at the 900 × 600 minimum window size
- Made Excel printer/page settings non-fatal when no compatible default printer is available

### Fixed

- Excel export no longer stops when `PageSetup.FitToPagesTall` is rejected by Excel or the active printer driver
